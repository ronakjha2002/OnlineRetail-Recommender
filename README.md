# 🛒 Shopper Spectrum
### Customer Segmentation & Product Recommendations in E-Commerce

---

## Overview

This project analyses over **500,000+ real transactions** from a UK-based online retail store to do two things:

1. **Segment customers** by their purchasing behavior using RFM analysis + KMeans clustering  
2. **Recommend products** a customer is likely to buy using item-based collaborative filtering

The end result is a **Streamlit web app** where you can:
- Type a product name → get 5 similar products instantly
- Enter a customer's RFM values → predict which segment they belong to (High-Value, Regular, Occasional, or At-Risk)

---

## 📊 Dataset

**UCI Online Retail II**  
Real transactions from a UK-based non-store online retailer (2009–2011)

| Source | Link |
|---|---|
| UCI ML Repository | https://archive.ics.uci.edu/dataset/502/online+retail+ii |
| Kaggle Mirror | https://www.kaggle.com/datasets/mathchi/online-retail-ii-data-set-from-ml-repository |

**Columns:**

| Column | Description |
|---|---|
| `Invoice` | Unique transaction ID (prefix 'C' = cancellation) |
| `StockCode` | Product code |
| `Description` | Product name |
| `Quantity` | Units purchased per transaction |
| `InvoiceDate` | Date and time of transaction |
| `Price` | Unit price in GBP (£) |
| `Customer ID` | Unique customer identifier |
| `Country` | Customer's country |

## 🚀 Quickstart

### 1. Clone the repo
```bash
git clone https://github.com/ronakjha2002/shopper-spectrum.git
cd shopper-spectrum
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Download the dataset
Download `online_retail_II.xlsx` from one of the sources above and place it inside the `data/` folder.

### 4. Run the notebook
Open and run `notebooks/shopper_spectrum_analysis.ipynb` end-to-end.  
This generates all model files inside the `models/` folder.

### 5. Launch the Streamlit app
```bash
streamlit run app/app.py
```

## 🧠 Methodology

### Part 1 — Customer Segmentation

**Feature Engineering (RFM):**
- **Recency** = days between snapshot date and customer's last purchase
- **Frequency** = number of unique invoices per customer
- **Monetary** = total spend (Quantity × Price) per customer

**Clustering:**
- Features normalized with `StandardScaler`
- Optimal k chosen using the **Elbow Method** + **Silhouette Score**
- Final model: `KMeans(k=4, init='k-means++')`

**Segments:**

| Segment | Recency | Frequency | Monetary | Strategy |
|---|---|---|---|---|
| 💎 High-Value | Low | High | High | Reward & retain |
| ✅ Regular | Medium | Medium | Medium | Upsell & engage |
| 🕐 Occasional | Any | Low | Low | Re-engagement |
| ⚠️ At-Risk | High | Low | Low | Win-back campaigns |

### Part 2 — Product Recommendation

- Build a **Customer × Product** pivot table (purchase quantities)
- Transpose to get **Product × Customer** matrix
- Compute **cosine similarity** between every product pair
- For any given product, return top-5 most similar products by similarity score
